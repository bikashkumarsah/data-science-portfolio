# Data Science Portfolio - Dataquest Data Scientist in Python

This repository is a recruiter-friendly portfolio of guided data science projects completed through the Dataquest Data Scientist in Python path. It shows practical work across Python, data cleaning, exploratory analysis, visualization, SQL, APIs, statistics, machine learning, and deep learning with PyTorch.

**Certificate:** [Dataquest Data Scientist in Python](certificates/dataquest-data-scientist-in-python.pdf)

## How to Review the Work

Start with the certificate and featured projects above, then open each project's `analysis.ipynb` for the full workflow. Each project folder includes a short README that explains the problem, methods, skills demonstrated, dataset, files, and what the project shows.

Most notebooks use Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn. The PyTorch project also requires `torch`. Raw CSV files live in `dataset/` so project folders stay focused on the analysis.

The Nasdaq Data Link project reads `NASDAQ_API_KEY` from the environment, or optionally a local `config.py` copied from `config.example.py`. `config.py` is listed in `.gitignore` so API keys are not committed.
