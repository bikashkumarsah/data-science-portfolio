# Predicting Insurance Costs

This project predicts individual medical insurance charges from demographic and personal health-related features.

## Problem

Estimate insurance charges and identify which features are most associated with higher costs.

## Methods

- Inspect distributions and missing values
- Transform skewed insurance charges
- Encode categorical predictors
- Train a linear regression model
- Evaluate residuals and model performance

## Skills Demonstrated

- Linear regression
- Log transformation
- Feature selection
- Residual diagnostics
- R2 and mean squared error evaluation

## Dataset

- `../../dataset/insurance.csv`

## Files

- [analysis.ipynb](analysis.ipynb): full notebook analysis

## What This Shows

This project demonstrates supervised regression modeling and interpretation of model drivers in a familiar business context.
