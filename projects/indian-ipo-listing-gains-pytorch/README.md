# Predicting Listing Gains in the Indian IPO Market with PyTorch

This project builds a binary classification model to predict whether an Indian IPO will generate listing gains.

## Problem

Use IPO market features to classify whether a listing is likely to trade above its issue price after listing.

## Methods

- Clean and inspect IPO market data
- Engineer a binary target for listing gains
- Scale input features for neural network training
- Build PyTorch tensors, datasets, and dataloaders
- Train and evaluate a neural network classifier

## Skills Demonstrated

- PyTorch model training workflow
- Binary classification
- Feature scaling with Scikit-learn
- Train/test splits
- Confusion matrix based evaluation

- `../../dataset/Indian_IPO_Market_Data.csv`
