# Predicting Employee Productivity with Tree Models

This project predicts garment employee productivity outcomes using decision tree based models.

## Problem

Classify employee productivity using operational and work-context features from a garment manufacturing dataset.

## Methods

- Explore productivity and workplace features
- Clean and prepare the dataset for modeling
- Train a decision tree classifier
- Compare performance with a random forest
- Evaluate classification performance with multiple metrics

## Skills Demonstrated

- Decision tree classification
- Random forest classification
- Train/test splits
- Accuracy, precision, recall, and F1 evaluation
- Model interpretation

## Dataset

- `../../dataset/garments_worker_productivity.csv`

## Files

- [analysis.ipynb](analysis.ipynb): full notebook analysis

## What This Shows

This project demonstrates practical classification modeling and the ability to compare interpretable tree models with ensemble methods.
