# Classifying Heart Disease with Logistic Regression

This project uses logistic regression to classify heart disease presence and interpret model coefficients.

## Problem

Predict whether heart disease is present and understand how selected clinical features affect the estimated odds.

## Methods

- Inspect and clean clinical tabular data
- Remove invalid placeholder values
- Select interpretable predictors
- Train a logistic regression classifier
- Interpret coefficients as odds relationships

## Skills Demonstrated

- Logistic regression
- Train/test splits
- Clinical feature cleaning
- Coefficient interpretation
- Classification evaluation

## Dataset

- `../../dataset/heart_disease.csv`

## Files

- [analysis.ipynb](analysis.ipynb): full notebook analysis

## What This Shows

This project demonstrates interpretable classification, with attention to both prediction and explaining model behavior.
