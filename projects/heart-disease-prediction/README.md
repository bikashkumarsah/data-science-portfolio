# Heart Disease Prediction

This project predicts heart disease risk using patient clinical features.

## Problem

Build a classifier that predicts whether a patient is likely to have heart disease from medical and demographic attributes.

## Methods

- Explore clinical feature distributions
- Clean unusual zero values and missing-style entries
- Encode categorical features
- Scale features for distance-based modeling
- Tune a K-nearest neighbors classifier with grid search

## Skills Demonstrated

- KNN classification
- Data cleaning for clinical-style tabular data
- One-hot encoding
- Feature scaling
- GridSearchCV
