# Credit Card Customer Segmentation

This project segments credit card customers into groups that can support different business and marketing strategies.

## Problem

Group customers based on demographic, account, transaction, and credit behavior so each segment can be interpreted and acted on.

## Methods

- Inspect numeric and categorical customer features
- Encode categorical variables
- Scale features before clustering
- Use the elbow method to choose a cluster count
- Profile clusters using customer behavior and demographics

## Skills Demonstrated

- K-Means clustering
- Feature engineering
- Data scaling
- Cluster interpretation
- Business-oriented analysis

- `../../dataset/customer_segmentation.csv`
