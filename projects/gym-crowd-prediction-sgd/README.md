# Gym Crowd Prediction with SGD

This project predicts campus gym crowd levels using stochastic gradient descent regression.

## Problem

Estimate when the gym is likely to be crowded so users can choose better workout times.

## Methods

- Explore time, day, weather, and crowdness features
- Split the data into training and test sets
- Scale predictors for SGD regression
- Train an SGDRegressor model
- Evaluate prediction error and fit quality

## Skills Demonstrated

- Stochastic gradient descent regression
- Feature scaling
- Train/test splits
- Mean squared error, mean absolute error, and R2
- Practical model evaluation

- `../../dataset/crowdness_gym_data.csv`
